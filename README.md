# Warax Visuals (Fabric 1.16.5)

Клиентский визуальный мод. **Меню — Правый Shift** (клавишу можно сменить в «Управление»).

## Что внутри (v2.0.0)
**Визуалы:** соотношение сторон, FOV, зум на C, свой прицел, ViewModel (позиция/размер предмета в руке),
медленный взмах, без анимации смены предмета, партиклы удара (криты/зачарование/сердечки), хитбоксы (F3+B),
свой ник от 3-го лица, без тряски при уроне, без покачивания камеры.
**Мир:** яркость, время суток, ясная погода, без тумана, цвет неба/тумана, круги при прыжке, China Hat,
след за игроком, своя обводка блока (с заливкой), без частиц ломания блоков.
**Экран:** без огня, воды, тыквы, виньетки, портала, боссбара, скорборда, анимации тотема.
**HUD:** водяной знак, список модулей, FPS, CPS, координаты, пинг, часы, скорость (б/с), сервер, время сессии,
клавиши, броня, эффекты зелий, Target HUD, счётчик предметов (тотемы, яблоки, перлы, пузырьки опыта),
прочность предмета в руке, компас, уведомления о вкл/выкл модулей.
**Меню:** 10 градиентных тем, категории Визуалы / Мир / Экран / HUD.

В меню: ЛКМ по модулю — вкл/выкл, ПКМ — настройки, клик по `[клавише]` — назначить бинд
(ПКМ по ней или Backspace — сбросить). Настройки сохраняются в `config/waraxvisuals.json`.

## Как собрать jar
**Вариант 1 — GitHub (проще всего):** создайте репозиторий, загрузите туда содержимое папки,
откройте вкладку Actions → дождитесь сборки → скачайте артефакт `waraxvisuals`.

**Вариант 2 — локально (нужен JDK 17):**
```
gradle wrapper --gradle-version 7.3.3
./gradlew build            # Windows: gradlew.bat build
```
Готовый файл: `build/libs/waraxvisuals-2.0.0.jar`.

## Установка
Нужны Fabric Loader и Fabric API для 1.16.5 (лаунчер Warax Visuals ставит их сам).
Положите jar в папку модов профиля или добавьте кнопкой «Добавить .jar» на странице «Моды».
